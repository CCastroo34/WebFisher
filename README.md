La `src` es simplemente el **código fuente del proyecto**.
Está pública porque **me importa exactamente cero que la tengas**.

Descárgala.
Estúdiala.
Cópiala.

**Haz lo que quieras.**

Solo hay un pequeño detalle:

> **Ahora intenta configurarla y hacer que funcione.** 💀

Porque encontrar archivos es fácil.
**Entenderlos, configurar el proyecto y conseguir que compile ya es otra historia.**

Así que antes de presumir que “encontraste mi código”:

