# 🎣 Fisher

> A web fishing game developed with love, chaos, and way too much fishing.

**Fisher** is a browser-based fishing game where you can explore, fish, collect catches, and enjoy a simple but addictive gameplay experience.

## ✨ Features

* 🎣 Fishing system
* 🐟 Different fish to catch
* 💰 Collect and progress
* 🌐 Play directly in your browser
* ⚡ Lightweight and fast
* 🎮 Simple and fun gameplay

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/CCastroo34/WebFisher.git
```

Enter the project folder:

```bash
cd WebFisher
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by the terminal.

## 🚀 Deployment

The project can be deployed using services such as **Vercel** or any other platform that supports modern web applications.
